# Security Shizz

## Cybersecurity based stuffs. Some red, some blue, all good.

## team_red
Scripts, payloads, shells, etc. surrounding offensive security testing procedures.

**s3_fuzz.py** - A python3 based fuzzing script for discovering S3 accounts via a wordlist/dictionary attack. This can help when testing for public file and ACL vulnerabilities within AWS S3.


## team_blue
 Configurations, scripts, and information regarding defensive security measures.

ooshutup10.cfg - My personalized configuration file for locking down and "quieting" a Windows 10/11 installation. Again, this is MY configuration so you may want to play around with it to further disable or re-enable items.  This configuration requires using the application [O&O ShutUp10++ found here.](https://www.oo-software.com/en/shutup10)
